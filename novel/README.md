# Novel

Plain markdown chapter files go here. Write them as normal Markdown —
no Jekyll front matter needed; these files aren't run through Jekyll
at all, they're copied into the built site as-is by the deploy workflow
(`.github/workflows/pages.yml`) so the live site can fetch them
directly at `/novel/<filename>.md`.

Suggested filename pattern: `01-<slug>.md`, `02-<slug>.md`, ... so they
sort in reading order.
