the # Novel

Plain markdown chapter files go here. Write them as normal Markdown —
**don't add a YAML front-matter block** (a `---`-delimited header).
Jekyll only runs its page/layout pipeline on files that have one;
without it, a file is left untouched and copied straight into the
build, so these end up served as plain text at
`/novel/<filename>.md` for the site to fetch directly.

Suggested filename pattern: `01-<slug>.md`, `02-<slug>.md`, ... so they
sort in reading order.
